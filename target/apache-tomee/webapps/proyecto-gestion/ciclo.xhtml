Qué fases ve en la consola

Petición Fases que se recorren
GET inicial (abrir la página) RESTORE_VIEW, RENDER_RESPONSE. No se valida ni se ejecuta la acción.
POST válido (código A-101) RESTORE_VIEW, APPLY_REQUEST_VALUES, PROCESS_VALIDATIONS, UPDATE_MODEL_VALUES, INVOKE_APPLICATION, RENDER_RESPONSE.
POST inválido (vacío o "Al") RESTORE_VIEW, APPLY_REQUEST_VALUES, PROCESS_VALIDATIONS y salta a RENDER_RESPONSE. No se actualiza el bean ni se ejecuta consultar().
